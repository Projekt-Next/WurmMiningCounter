# Prospecting Scenarios

Status: **current scenario reference for WurmMiningCounter 1.8.4**. These scenarios define concrete input/event sequences and expected outcomes for the Prospecting / Vein Context domain. Exact evidence and literal registries belong to `PROSPECTING_DOMAIN_BASELINE.md`; functional rules belong to `PROSPECTING_SPECIFICATION.md`; runtime boundaries belong to `ARCHITECTURE.md`.

Rows marked `OPEN`, `DATA-NEEDED`, or `DEFERRED` are unresolved only in the aspect explicitly named in the row. Their already implemented safety behavior remains authoritative.

## Reset and cave-transition scenarios

| ID | Input / action | Expected domain result | Preserved state |
| --- | --- | --- | --- |
| R01 | `You enter the cave.` | The exact normalized line clears the matching profile's Vein Context, retained PlainRock result, pending Prospecting/attempt state, and Nearby Scan state in the ordered Context consumer. | Mining counters, Total, Moment of Inspiration, and other profiles. |
| R02 | `You leave the cave.` | Same per-profile clearing behavior as cave entry. | Mining counters, Total, Moment of Inspiration, and other profiles. |
| R03 | `Reset Prospecting Results` from either `Prospecting Results` or `Nearby Scan` | One confirmed action awaits the selected profile's existing Ordered Context reset barrier and clears Vein, PlainRock, pending Prospecting/attempt, and Nearby state. | Mining counters, Total, Moment of Inspiration, and other profiles. |
